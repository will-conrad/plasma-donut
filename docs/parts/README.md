# docs/parts/

One note per part the firmware talks to, plus `specs.csv` (each spec with its datasheet page).

These notes are copies of the ones in the OneDrive datasheet catalogue (`CAPSTONE/Microcontroller-PCB/datasheets/parts/`). Their `../pdf/…` and `../text/…` links only resolve there, next to the PDFs and the extracted text. The PDFs aren't in this repo. To follow a `(part p.N)` citation, open `datasheets/pdf/<part>.pdf` at page N, or search the text with `datasheets/search.py`.
