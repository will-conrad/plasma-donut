# docs/parts/

One note per part the firmware talks to, plus `specs.csv` (each spec with its datasheet page).

The PDFs are in [`hardware/datasheets/`](../../hardware/datasheets/INDEX.md), and the links in these cards open them at the cited page. To follow a `(part p.N)` citation, open `hardware/datasheets/<part>.pdf` at page N, or read `## Page N` in `<part>.md` beside it. To search every datasheet: `python3 hardware/datasheets/search.py <words>`.
